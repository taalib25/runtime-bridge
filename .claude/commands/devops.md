# DevOps: Hermes Runtime Operator

You are acting as a DevOps expert for the Hermes Runtime Operator project. You have deep knowledge of this specific stack and should assist with infrastructure, CI/CD, Kubernetes, and Hetzner operations.

## Stack Overview

- **Cluster:** Single Hetzner VM (178.104.185.60), k3s managed via `hetzner-k3s` CLI
- **Ingress:** Traefik (k3s built-in) with Let's Encrypt TLS via ACME HTTP-01
- **DNS:** Cloudflare `*.hermeshq.net` → `178.104.185.60` (orange cloud / proxied ✓ — ports 80+443 open)
- **Bridge:** Go service in `hermes-bridge` namespace, image loaded directly into k3s via SSH pipe (no registry)
- **CI/CD:** GitHub Actions `.github/workflows/bridge.yml` — SSH deploy on push to `main` / `go-bridge`
- **Auth:** `X-Bridge-Secret` header, secret in `bridge-auth` k8s secret
- **Storage:** PVCs via `hcloud-volumes` StorageClass (Hetzner Block Storage); Traefik ACME persisted on `traefik` PVC
- **Hetzner API token:** in `HCLOUD_TOKEN` env var; Firewall ID: `10864999` (hermes-test)

## Workspace ID Convention

Format: `tenant-{8 random hex chars}` e.g. `tenant-290f0b64`

- **Generated by the backend** before calling the bridge
- Same string used as: Helm release name, Kubernetes namespace, subdomain
- Backend stores it in DB linked to user: `users.workspace_id = "tenant-290f0b64"`
- Workspace URL: `https://{id}.hermeshq.net`

```python
# Python
import secrets
workspace_id = "tenant-" + secrets.token_hex(4)  # → tenant-290f0b64
```
```javascript
// JS/Node
const id = "tenant-" + crypto.randomBytes(4).toString("hex");
```
```bash
# Shell / curl testing
WID="tenant-$(openssl rand -hex 4)"
```

## Known Chart Schema Requirements (hermes-agent)

The chart has a strict JSON schema. `buildValues` in `bridge/helm.go` already handles these, but good to know:

| Requirement | Value set by bridge |
|-------------|-------------------|
| `service.enabled: true` | ✓ always set |
| `service.ports` — minItems: 1 | ✓ port 8642 (api-server) |
| `apiServer.enabled: true` | ✓ always set |
| `secrets.API_SERVER_KEY` | ✓ random hex per workspace |
| `imagePullPolicy: IfNotPresent` | ✓ chart default, never overridden |

Helm `SkipCRDs: true` — bridge SA lacks cluster CRD permissions, chart has a CRD it tries to install.

## CI/CD Workflow

```
Every PR / push:
  └── go test ./bridge/... -v
  └── go vet ./bridge/...

Push to main / go-bridge only:
  └── docker build -t hermes-bridge:latest .
  └── docker save | ssh root@VM "k3s ctr images import -"
  └── Sync charts/hermes-agent → ConfigMap hermes-agent-chart
  └── kubectl apply -f deploy/rbac.yaml deploy/deployment-test.yaml
  └── kubectl rollout restart + status
  └── Smoke test /healthz /readyz /v1/instances
```

**Required GitHub secret:** `HETZNER_SSH_PRIVATE_KEY` (private key for `root@178.104.185.60`)

**Common CI failures and fixes:**

| Symptom | Cause | Fix |
|---------|-------|-----|
| Bridge pod CrashLoopBackOff | Wrong env var names in deployment | Check `BRIDGE_CHART_PATH`, `BRIDGE_SYNC_INTERVAL` (not `CHART_PATH`) |
| Smoke test 401 | `bridge-auth` secret missing in namespace | `kubectl create secret generic bridge-auth -n hermes-bridge --from-literal=secret=$(openssl rand -hex 32)` |
| Smoke test 522 | Cloudflare can't reach origin | Check firewall has ports 80+443 open; check Traefik is running |
| Smoke test 404 | Traefik ingress not routing | Check ingress host matches, check `ingressClassName: traefik` |
| Tests: prometheus panic | Duplicate metric registration in tests | Pass `prometheus.NewRegistry()` per test bridge, not nil |
| Workspace resources in `default` ns | Shared `action.Configuration` uses bridge ns | Fixed: per-op `helmConfigForNamespace(workspaceID)` in helm.go |
| Helm install: CRD forbidden | Bridge SA can't create CRDs cluster-wide | Fixed: `install.SkipCRDs = true` |
| Helm install: schema validation error | Chart requires `service.ports`, `apiServer`, `API_SERVER_KEY` | Fixed in `buildValues` — check `bridge/helm.go` if schema changes |
| Workspace namespace not created | `createNamespace: false` default | Send `"createNamespace": true` in WorkspaceSpec; bridge honors `spec.CreateNamespace \|\| config.CreateNamespace` |
